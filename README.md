# zer0-gopass-tui

> Интеграционный контракт карточки принят в соседнем проекте:
> `/home/zer0/Projects/pet-projects/zer0-waypass/docs/FIELD-CONTRACT.md`.
> TUI создаёт encrypted manifest и отдельные encrypted value entries
> copy-on-write согласно FIELD-CONTRACT.md v1.

Локальная keyboard-first TUI-обёртка для `gopass` на Go.

## Возможности

Приложение даёт один терминальный интерфейс для:

- поиска записей по пути;
- создания field bundle через единую форму со всеми стандартными полями;
- просмотра и редактирования отдельных полей;
- удаления только после явного подтверждения;
- создания записей со стандартными и произвольными полями;
- явного раскрытия выбранного secret-поля;
- явной миграции legacy-записи в field bundle.

TUI не реализует криптографию, не читает `.gpg`-файлы напрямую и не управляет
общим `gpg-agent`.

## Управление

```text
┌─ zer0-gopass-tui ──────────────────────────────┐
│ / github                                       │
├────────────────────────────────────────────────┤
│ > github/account                               │
│   github/work                                  │
├────────────────────────────────────────────────┤
│ Enter: изменить n: новая  d: удалить  q: выход │
└────────────────────────────────────────────────┘
```

На первом экране активна левая панель: `↑/↓` выбирают запись, а полная карточка
сразу отображается справа. `→`/`l`, `Enter` или `Tab` переводят фокус в готовую
форму, `←`/`h` возвращают его к списку;
`/` — поиск, `n` — новая запись, `d` — удаление с подтверждением.
`q` закрывает приложение из любого экрана командного режима; во время ввода
текста буква `q` остаётся обычным символом. Для multiline-поля `Ctrl+J` добавляет перевод строки.
Команды работают в английской и русской раскладках; текстовый ввод раскладку
не преобразует.

В форме создания или редактирования на секретном поле нажмите `g`, чтобы
открыть генератор пароля. Можно настроить длину, регистр, цифры, спецсимволы и
включение неоднозначных («опасных») символов. По умолчанию используется
24-символьный безопасный профиль; `Enter` на поле оставляет ручной ввод.
Во время ручного ввода `Ctrl+R` показывает или снова маскирует пароль.

### Выборочная синхронизация с Bitwarden

В форме создания или полного редактирования `b` переключает checkbox
`Синхронизировать с Bitwarden`. Флаг хранится внутри зашифрованного bundle.
После каждого успешного создания или изменения отмеченной записи TUI создаёт
или обновляет соответствующий Login item в Bitwarden. Снятие checkbox прекращает
последующие синхронизации, но не удаляет уже существующий item из Bitwarden.

Интеграция использует локальный Vault Management API, чтобы пароль не попадал в
argv процессов. Перед запуском TUI разблокируйте CLI и поднимите API только на
localhost:

```bash
./scripts/run-with-bitwarden
```

Скрипт сам запросит master password, запустит `bw serve` на `127.0.0.1:8088`,
запустит TUI и остановит созданный сервер после выхода. Если разблокированный
сервер на этом порту уже работает, скрипт сразу использует его. Порт можно
переопределить через `ZER0_GOPASS_BITWARDEN_PORT`.

Чтобы добавить кнопку **Zer0 Gopass TUI** в системное меню приложений:

```bash
./scripts/install-launcher
```

Ручной вариант:

```bash
export BW_SESSION="$(bw unlock --raw)"
bw serve --hostname 127.0.0.1 --port 8088 --session "$BW_SESSION"
```

При другом адресе задайте `ZER0_GOPASS_BITWARDEN_URL`. Сбой Bitwarden не
откатывает подтверждённое сохранение gopass и отображается в карточке.

## Модель записей

Форма новой записи сразу показывает все стандартные поля FIELD-CONTRACT v1.
Пользователь заполняет только нужные; пустые поля не попадают в manifest и не
создают value entries. `Enter` открывает редактор выбранной строки,
`Ctrl+S` сохраняет всю форму. Custom-поля добавляются из карточки записи.

## Границы безопасности

- команды запускаются только через `os/exec` с фиксированными argv, без shell;
- пароль не передаётся в argv, логи, файлы или stdout TUI;
- значения передаются `gopass insert --force` только через stdin;
- скрытые значения не показываются без отдельного явного действия;
- private keys, tokens и recovery codes имеют secret visibility; notes по
  контракту public, но всё равно считаются чувствительными и не логируются;
- список содержит только пути записей — они считаются открытыми метаданными;
- удаление и другие необратимые операции требуют подтверждения.
